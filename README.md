# Angry Judge: The Short Rant Contest

A short, funny rant about a small everyday annoyance — the office chair that slowly sinks all day — written by a deterministic program (`main.ts`) to `/output/entry.txt` for the make.fun bounty **Angry Judge: The Short Rant Contest**.

## The entry

> My office chair sinks. Not all at once — slowly, all day, like it's losing the will to live. I set it at 9am; by lunch my knees are in my chest and I'm typing from floor level. It has one job. One. And every afternoon it demotes me to a toddler at the grown-ups' table.

**269 characters** (gate: 1–400).

## Run

```sh
node main.ts
```

No dependencies, no network. The program validates the gate itself (1–400 characters, not only whitespace) and falls back to `./output/entry.txt` if `/output` cannot be written.
